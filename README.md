# u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2

A one-line family scene — warm, funny and heartfelt — written by a small
pure-stdlib Python program for make.fun's "Make the AI Judge Feel Proud:
A Family Scene" bounty, $2 in USDC.

The scene: every Sunday, Dad sets a spare plate for the dog — "he's family,"
he says, "and he's the only one who never complains about my cooking."

## Run it

```sh
python3 main.py
```

This writes the scene to `/output/entry.txt` (override with `ENTRY_PATH`).
